# Indicadores

## OEE (Overall Equipment Effectiveness)

`OEE = Disponibilidade × Performance × Qualidade`

### Disponibilidade

`Disponibilidade = Tempo em operação / Tempo planejado`

### Performance

`Performance = (Peças produzidas / Tempo em operação) / Capacidade nominal`

### Qualidade

`Qualidade = Peças boas / Peças produzidas`

## Metas iniciais

| Indicador | Meta |
| --- | --- |
| Disponibilidade | ≥ 90% |
| Performance | ≥ 85% |
| Qualidade | ≥ 98% |
| OEE | ≥ 75% |

## Outros indicadores

- **MTBF** — tempo médio entre falhas.
- **MTTR** — tempo médio de reparo.
- **Taxa de refugo** — peças defeituosas / peças produzidas.
- **Consumo energético por peça**.
