# Glossário

| Termo | Definição |
| --- | --- |
| **PLC** | Programmable Logic Controller; controlador usado em automação industrial. |
| **Telemetria** | Conjunto de leituras de sensores enviadas periodicamente. |
| **Sensores** | Dispositivos que medem grandezas (temperatura, pressão, etc.). |
| **OEE** | Overall Equipment Effectiveness; eficiência global do equipamento. |
| **Disponibilidade** | Fração do tempo planejado em que o equipamento operou. |
| **Performance** | Relação entre produção real e capacidade nominal. |
| **Qualidade** | Fração de peças boas sobre o total produzido. |
| **MTBF** | Mean Time Between Failures; tempo médio entre falhas. |
| **MTTR** | Mean Time To Repair; tempo médio de reparo. |
| **OPC-UA** | Protocolo padrão de comunicação industrial. |
| **Modbus** | Protocolo de comunicação industrial amplamente usado em PLCs. |
| **MQTT** | Protocolo de mensagens leve, comum em IoT. |
